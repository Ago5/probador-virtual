Backend corriendo correctamente. Así se ve el widget en tu tienda.

Cómo embeber en Tienda Nube

Pegá este código en Personalización → Editar código del tema → snippets/probador.html y luego incluilo en la página de producto con {% include 'probador' %}:

<!-- Probador Virtual -->
<button onclick="document.getElementById('pv-modal').style.display='flex'">
  👟 Probarte este zapato
</button>

<div id="pv-modal" style="display:none;position:fixed;inset:0;background:rgba(0,0,0,0.6);z-index:9999;align-items:center;justify-content:center;">
  <div style="background:#fff;border-radius:16px;overflow:hidden;width:min(540px,95vw);">
    <iframe
      src="https://TU-APP.onrender.com/widget"
      width="100%" height="700" frameborder="0"
    ></iframe>
  </div>
</div>

<script>
  // Cerrar modal cuando el widget manda señal
  window.addEventListener("message", e => {
    if (e.data === "cerrar-probador")
      document.getElementById("pv-modal").style.display = "none";
  });
</script>
